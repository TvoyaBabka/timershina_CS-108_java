# Ответы на контрольные вопросы по ПР 2
1. Что такое массив и для чего он используется? <br/>
   Массив - это хранилище данных, которое можно представить в виде ячеек и в каждую можно поместить данные
3. Чем отличается цикл for от while ? <br/>
   Цикл for выполняется определенное количество раз, а while - пока условие остается верным
5. Что делает оператор break в цикле? <br/>
   Прерывает цикл
7. Как работает оператор switch-case ? <br/>
   Есть кейс с вариантами событий, которые выполняются при определенных условиях (типа if-else, но запись проще)
9. Зачем нужен оператор default в switch-case ? <br/>
  Если не выполняется ни один вариант кейса, то выпролняется то, что прописано в дефолте
11. Что такое метод (функция)? <br/>
  Это фрагмерт кода, который позволяет выполнеять какие-либо действия
13. Как объявить метод, который принимает параметры и возвращает результат? <br/>
    Сначала прописываем тип данных, потом имя и в скобках уже параметры 
15. В чём преимущество вынесения логики в отдельные методы? <br/>
  В том, что их можно вызывать повторно и не нужно по 10 раз писать одно и то же, засоряя код
17. Почему методы «атаковать» и «лечиться» удобно сделать отдельными функциями? <br/>
    Потому что это разные действия

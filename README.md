# Ответы на контрольные вопросы
1. В чём отличие между break и continue в цикле? <br/>
break используется для выхода из цикла, а continue для пропуска текущей итерации
2. Почему массив maze должен быть объявлен как char[][] , а не как String[][] ?  <br/>
потому что в массиве хранятся символы, а не строки

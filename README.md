# Контрольные вопросы по Java

**Общие понятия**
1. Что такое класс в Java?  
Класс это как шаблон, по которому делают объекты
2. Чем класс отличается от объекта?  
Класс это шаблон, а объект это определенная вещь по этому шаблону
3. Что такое поля класса? Приведите примеры.  
Поля это характеристики объекта например имя,тип,сила
4. Что такое методы класса? Приведите примеры.  
Методы это действия объекта. например показать свойства
5. Какой оператор используется для создания объекта в Java?  
new

**Конструкторы**
1. Что такое конструктор в Java и для чего он нужен?  
Конструктор создаёт объект и задаёт ему первоначальные значения
2. Чем конструктор отличается от обычного метода?  
Он вызывается при создании объекта и ничего не возвращает
3. Когда вызывается конструктор?  
При создании объекта через new
4. Что произойдёт, если в классе не определить конструктор явно?  
Java создаст пустой конструктор сам
5. Чем отличается конструктор по умолчанию от конструктора без аргументов?  
Конструктор по умолчанию и конструктор без аргументов почти одинаковые, они создают объект без параметров
6. Что такое параметризованный конструктор?  
Конструктор, который принимает значения для полей при создании объекта
7. Что означает перегрузка конструктора?  
Когда у класса несколько конструкторов с разными параметрами

**Ключевое слово this**
1. Что такое ключевое слово this в Java?  
this ссылается на текущий объект
2. Зачем в конструкторе часто используется this?  
Чтобы отличить поля объекта от локальных переменных с таким же именем

**Методы**
1. Чем отличаются методы экземпляра от статических методов?  
Методы экземпляра работают с объектом, а статические с классом
2. Что означает возвращаемый тип метода?  
Это то, что метод возвращает
3. В чем разница между методами, которые возвращают значение, и методами void?  
Методы, которые возвращают значение, дают результат, а void просто делают что-то без возвращения результата
4. Что такое абстрактные методы и где они применяются?  
Методы без тела, их реализуют в других классах
5. Как вызвать метод объекта?  
объект.метод()

**Модификаторы доступа**
1. Назовите все виды модификаторов доступа в Java.  
public, private, protected, default
2. В чем разница между public и private?  
Public видно всем, private только внутри класса
3. Для чего используется protected?  
Видно в наследниках и внутри пакета
4. Что произойдет, если модификатор доступа не указан (default)?  
Доступ к элементу будет только внутри одного пакета
5. Как модификаторы доступа помогают реализовать инкапсуляцию?  
Они скрывают данные и защищают их от прямого доступа

**Статические члены (static)**
1. Чем статическое поле отличается от нестатического?  
Статическое одно на все объекты, нестатическое у каждого своё
2. Как получить доступ к статическому полю или методу?  
Через имя класса Класс.поле или 'Класс.метод()'
3. Можно ли в статическом методе обратиться к нестатическому полю? Почему?  
Нет, потому что нет конкретного объекта
4. Можно ли перегружать статические методы?  
Да, так же как обычные методы
